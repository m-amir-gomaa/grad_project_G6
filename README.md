# University Timetabling — Graduation Project G6

Generate and repair schedules for lectures, sections, labs, and examinations across the first, second, and summer terms. The initial case study is the Faculty of Computers and Informatics, Tanta University, Egypt.

Each university saves a simple **building → floor → room** layout. Scheduling uses that layout, room availability, staff commitments, and student registrations. Default timetable views follow the faculty's published Arabic schedules.

- [Default Tanta timetable formats](docs/TIMETABLE-FORMAT.md)

This initial commit contains project documentation. The specification describes the intended implementation; a real faculty timetable requires confirmed room data and an authorized registration export.
